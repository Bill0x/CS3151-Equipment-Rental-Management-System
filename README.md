# CS3151 — Equipment Rental Management System

Software Engineering project for Effat University.

## Project idea
An Equipment Rental Management System that helps a rental business track equipment that is available, rented, overdue, or under maintenance. The system also supports rentals, returns, payment records, and customer-related workflows.

## Main use cases
- View Available Equipment
- Rent Equipment
- Return Equipment
- Track Overdue Rentals
- Update Equipment Status
- Process Payments

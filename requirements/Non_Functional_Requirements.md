# Non-Functional Requirements

## Equipment Rental Management System

1. **Security** — Only authorized users can access and modify system data.
2. **Usability** — The system should be simple and easy to use.
3. **Performance** — The system should respond to user actions within a few seconds.
4. **Reliability** — The system should operate correctly without frequent errors or crashes.
5. **Availability** — The system should be available whenever employees need to use it.
6. **Backup and Recovery** — The system should regularly back up data and allow recovery if data is lost.
